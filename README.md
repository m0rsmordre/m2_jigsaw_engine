# Balık Yapboz Yardımcısı (m2_jigsaw_engine)

Metin2 Balık Yapboz etkinliği için bağımsız hayran yardımcısı. Vite + React + TypeScript.

## Geliştirme

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel

Root Directory: repo kökü (`web` içeriği). Framework: Vite. Build: `npm run build`, Output: `dist`.

## Not

Bu proje bağımsız bir hayran yapımıdır; Metin2 / Gameforge ile resmi bağlantısı yoktur.
